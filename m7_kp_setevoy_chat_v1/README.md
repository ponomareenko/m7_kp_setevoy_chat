# Сетевой чат

Учебное консольное клиент-серверное приложение на Java для обмена текстовыми сообщениями через TCP-сокеты.

## Текущий функционал

- сервер принимает подключение одного клиента;
- адрес сервера и порт загружаются из файлов `settings.txt`;
- клиент запрашивает имя пользователя и передаёт его серверу;
- клиент отправляет введённые в консоли сообщения;
- сервер принимает сообщения, выводит их в консоль и отправляет ответ клиенту;
- сообщения записываются в `client/file.log` и `server/file.log` без очистки предыдущих записей;
- команда `exit` завершает работу клиента.

## Структура проекта

- `server` — серверное приложение;
- `client` — клиентское приложение.

Проект собирается с помощью Maven и использует Java 25.

## Запуск

1. Указать порт в `server/settings.txt`.
2. Указать адрес сервера и такой же порт в `client/settings.txt`.
3. Запустить `server/src/main/java/ru/netology/Main.java`.
4. Запустить `client/src/main/java/ru/netology/Main.java`.
5. Ввести имя и начать отправлять сообщения.

## Ограничения текущей версии

Сервер пока обслуживает только одного клиента. Поддержка нескольких клиентов и общая рассылка сообщений ещё не реализованы.
