# Проверка чат-приложения

| Статус | Описание                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
|--------| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [x]    | Пустое сообщение роняет обработчик. В `ClientHandler.run()` строка разбирается как `reader.readLine().split("&")`, дальше берётся `in[2]`. Если просто нажать Enter, последний элемент окажется пустым, `split` его отбросит, и на `in[2]` вылетит `ArrayIndexOutOfBoundsException` — для пользователя чат просто молча перестаёт работать. Поможет `split("&", 3)` и проверка длины массива перед обращением к элементам. Заодно решится проблема с `&` внутри текста сообщения, о которой вы написали в «Ограничениях». |
| [x]    | `readLine()` используется без проверки на `null`. Когда клиент закрывает окно терминала, метод возвращает `null`, и на сервере получается `NPE` — и в цикле регистрации имени, и в основном цикле. Стоит читать строку в переменную и выходить из цикла, если она `null`.                                                                                                                                                                                                                                                 |
| [x]    | Чтение настроек (`saveSettings`) падает, если в `settings.txt` попадётся пустая строка: `indexOf('=')` вернёт `-1`, и `substring(0, -1)` бросит исключение. Стоит пропускать строки без `=` и проверять, что нужные ключи прочитались.                                                                                                                                                                                                                                                                                    |
| [ ]    | Метод `saveSettings()` полностью продублирован в клиенте и сервере. Общий код удобно вынести в отдельный модуль `common` и подключить к обоим.                                                                                                                                                                                                                                                                                                                                                                            |
| [x]    | `throw new RuntimeException(e)` при ошибке подключения лучше заменить на понятное сообщение пользователю, например: `Не удалось подключиться к серверу localhost:8080`.                                                                                                                                                                                                                                                                                                                                                   |
| [ ]    | Добавить уведомление участникам о входе и выходе пользователей. Для этого достаточно вызвать `broadcast()` в `addClient()` и `removeClient()`.                                                                                                                                                                                                                                                                                                                                                                            |
| [x]    | Добавить `server/file.log` и `client/logs/*.log` в `.gitignore`, так как это результат работы приложения и его не стоит хранить в репозитории.                                                                                                                                                                                                                                                                                                                                                                            |
| [ ]    | Добавить Javadoc к основным методам, особенно там, где описывается формат строки протокола.                                                                                                                                                                                                                                                                                                                                                                                                                               |
